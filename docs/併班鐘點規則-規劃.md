# 併班課堂與鐘點規則 — 規劃

> 路線：**沿用「特殊標記＝併班」單一入口，不新增課表欄位**。
> 適用情境：一般學科併班、本土語合班、英資班、樂團與社團合奏。

## 一、判定方式（單一入口）

```
併班 = 該堂課表列的「特殊標記」含「併班」（別名「合班」，寫法 併班／合班 都認）
相容判定（只為舊資料，不再當主要入口）：
  班名為多班        例 707、708（DateUtils.isCombinedClass）
  課堂屬性含併班     例 attr = 併班
```

- 正規化：`FieldMap.normalizeSpecialTags`（src/domain/field-map.js:717）。`合班`→`併班`、`綁班`→`綁課`。
- 判定器：`UiLineTemplate.hasScheduleSpecialTag`（src/modules/ui-line-template.js:309），
  抽屜（MatchDrawerModal.vue:34）與入口（ui-approval.js:1352）共用同一支。
- 不再需要「併班群組」欄位。要讓本土語、英資班的兩列互相認得，**兩列都勾併班**即可：
  候選人清單本來就是「同節次、其他教師、其課堂也標併班」，
  下拉選單已顯示`姓名（班級／科目）`（CompareModal.vue:55），跨群誤配由教學組自己挑。

## 二、課表怎麼設定（已完成）

`ScheduleEditModal.vue` 課程屬性下方新增「併班／合班（同節多班一起上，例：本土語、英資班、樂團）」勾選：

- 勾選 → 寫入 `特殊標記＝併班`（保留其他標記，例如超鐘點、綁課）。
- 取消 → 移除 `併班` 與別名 `合班`。
- `課程屬性＝巡堂` 時禁用（巡堂存檔本來就會清空標記）。

存檔路徑不用改：`saveScheduleCell` 已用 `specialTagList(scheduleForm.specialTags)` 寫回特殊標記
（src/modules/ui-admin.js:1404），`併班` 不在屬性衍生清單裡，所以會原樣保留。

## 四、鐘點：可選「不扣鐘點」（本次新增）

併班原本只能「依假別扣鐘點」。現在申請單多一欄 `鐘點規則`：

| 端 | 行為 |
| --- | --- |
| 代課（併班任課教師） | 一律不支領代課費 |
| 請假老師 | `鐘點規則` 空白＝依假別扣（原行為）；填 `不扣鐘點`＝這堂鐘點照領 |

### 教學組怎麼設

「調代課模擬對照」的併班上課面板多了「請假教師鐘點」：

- **依假別扣鐘點（預設）**：與改版前完全相同。
- **不扣鐘點（併班上課，請假教師鐘點照領）**：超鐘點表不扣減；第8節併班也照領第8節鐘點。

需要事後改：歷史紀錄編輯的併班紀錄同樣可改「請假教師鐘點」，走 `saveHistoryEdit`。

## 五、驗收條件

1. 課表勾「併班」後，該教師該節的代課抽屜出現「↩ 併班上課」，按下不再被擋。
2. 本土語兩列（`801本土語A`、`802本土語A`）都勾併班後，同節次互相出現在對方的併班教師下拉。
3. 取消勾選後特殊標記載併班消失，其他標記（超鐘點、綁課）不受影響。
4. 舊資料（無鐘點規則欄）結算結果與改版前完全相同。
5. 併班面板選「不扣鐘點」送出後，申請單 `鐘點規則` 為 `不扣鐘點`；超鐘點表該師實得節數不減，備註寫「併班不扣鐘點N節」。
6. 同一筆併班選回「依假別扣鐘點」，超鐘點表回原本的扣減節數與「扣N節」備註。
