# RDQ 需求規格：統一課表與經費來源資料口徑

## 一句話任務
統一課表、來源快照、月報與會計分表的判定口徑，衝突時提示而不靜默改分國教。

## ✅ 已確認
- 來源快照優先；與結算時有效課表衝突時，標記衝突並暫停該節自動分表。（Ⅲ）
- 教師未填寫、課格未列出或來源留白時，均視為預設經費，不需人工確認；只有格式錯誤、歧義或明確來源與課表衝突才進入檢核。（Ⅲ）
- 整理範圍包含程式與教師資料，不納入教師課表資料改寫。（Ⅲ）
- 既有月份結果不可變，不依新規則全面重算。（Ⅲ）
- 既有教師資料改寫前須先備份。（Ⅲ／預設確認）

## ❓ 假設
- 來源快照以教師、學期、星期、節次、班級、經費計畫為最小識別資料。
- 衝突資料先進入檢核報告，不自動選國教、不刪除原資料。
- 教師資料整理限於固定超鐘點欄位與「鐘點支出計畫」JSON。
- 月報與匯出共用同一個來源解析器及同一份衝突結果。

## ➕ 已採納（象限Ⅳ）
- 無。使用者選擇「先這樣，直接開始」，未另採納額外建議。

## ❌ 排除項
- 不重算或覆蓋既有月份歷史報表。
- 不直接改寫教師課表的教師鍵、班級、日期與課堂屬性。
- 不刪除無法判定的來源資料；留白與快照缺漏直接採預設經費，歧義或明確來源與課表衝突才進入檢核。

## 📋 一段式需求規格
請在專案 **school-substitution-sys** 中，統一課表畫面、固定超鐘點節次、教師的「鐘點支出計畫」快照、月報分配與會計 Excel 分表的來源判定。以教師、學期、星期、節次、班級與來源計畫建立可重複使用的來源解析器，來源快照優先；空白或未列出的經費來源視為預設經費；只有明確來源與結算時有效課表不一致時，才留下教師、節次、班級、快照來源與課表來源的衝突資訊，停止該節自動分表，不得靜默轉成「國教」。整理範圍包含程式與教師資料，教師資料只處理固定超鐘點欄位及「鐘點支出計畫」JSON，改寫前先備份並可預覽；既有月份歷史結果保持不變，教師課表資料不直接改寫。完成後讓來源顯示、月報分配與匯出分表共用同一結果，並補上衝突、課表更版、班級更名及快照缺課表的回歸測試。

## ✔ 驗收條件
- [ ] 同一節來源在設定畫面、月報與 Excel 分表使用同一解析結果。
- [ ] 快照與結算課表衝突時有明確提示與檢核資料，不自動落入國教。
- [ ] 教師資料備份、預覽與整理流程可驗證，且不改寫教師課表與歷史月份。
- [ ] 既有測試與新增衝突案例全部通過，並能驗證資優、無人機與小鐘點案例。
